# 🧮 문자열 덧셈 계산기 🧮
***
## 🎯 기능 구현 목록
***
### ⌨️ 입력
- [ ] 사용자로 부터 덧셈할 문자열 입력 받기
    - [ ] 덧셈 문자열 안내 메시지 출력
    - [ ] 사용자 입력 받기

### ⚙️ 로직

#### 입력 전처리
- [ ] 입력 문자열 앞뒤 공백 제거
- [ ] 빈 문자열이면 0 반환 후 종료

#### 구분자 처리
##### 기본 구분자 정의
- [ ] 구분자 집합(Set) 정의
    - [ ] `,` (콤마)
    - [ ] `:` (콜론)

##### 커스텀 구분자 처리 
- [ ] 커스텀 구분자 형식 검증
    - [ ] `//`로 시작하는지 확인
    - [ ] `\n`이 포함되어 있는지 확인
    - [ ] `//`와 `\n` 사이에 구분자가 존재하는지 확인 (최소 1자)
    


- [ ] 커스텀 구분자 추출
  - [ ] `//`와 `\n` 사이의 문자열을 구분자로 사용


- [ ] 커스텀 구분자를 구분자 집합에 추가
  - [ ] 기본 구분자(`,`, `:`) 집합에 커스텀 구분자 추가


##### 문자열 분리
- [ ] 구분자 집합을 사용하여 입력 문자열 분리
  - [ ] 기본 구분자(`,`, `:`) + 커스텀 구분자로 문자열 분리

#### 숫자 추출 및 검증
- [ ] 분리된 문자열을 정수로 변환
  - [ ] 각 토큰이 빈 문자열이면 0으로 변환
  - [ ] 숫자가 아닌 값이 포함된 경우 예외 발생
  - [ ] 음수가 포함된 경우 예외 발생

#### 덧셈 계산
- [ ] 변환된 정수들의 합 계산


- [ ] 계산 결과 반환

### 🖥️ 출력
- [ ] 계산 결과 출력 

### ⚠️ 예외 처리 

| 예외 상황 | 예외 타입 | 예시                 |
|----------|----------|--------------------|
| 음수 입력 | `IllegalArgumentException` | `1,-2,3`           |
| 숫자가 아닌 값 | `IllegalArgumentException` | `1,a,3`            |
| 커스텀 구분자 형식 오류 | `IllegalArgumentException` | `//\n1,2` (구분자 누락) |
| 잘못된 커스텀 구분자 형식 | `IllegalArgumentException` | `//;1;2;3` (\n 누락) |
