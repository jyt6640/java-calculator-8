# 🧮 문자열 덧셈 계산기 🧮
***
## 🎯 기능 구현 목록
***
### 1. 사용자 입력 처리

#### 1.1 사용자 입력 받기 
- [ ] 사용자로 부터 덧셈할 문자열 입력 받기
  - 예: ```1,2:3``` 또는 ```//;\n1;2;3```

#### 1.2 입력 검증하기
- [ ] 입력 문자열이 빈 문자열 인 경우 0 반환
  - 예: ```""```  → ```0```

### 2. 구분자 처리

#### 2.1 기본 구분자 처리
- [ ] 기본 구분자(`,`, `;`)로 문자열 분리
- [ ] 기본 구분자로 문자열 분리
  - 예: ```1,2:3``` → ```["1", "2", "3"]```

#### 2.2 커스텀 구분자 처리 
- [ ] 커스텀 구분자 형식 검증
    - [ ] String 길이가 5자 이하일 시 커스텀 구분자 형식이 아님
    - [ ] ```//```로 시작하고 ```\n```으로 끝나야 함

- [ ] 커스텀 구분자 추출
  - ```//```와 ```\n``` 사이의 문자열을 구분자로 사용
  - 예: ```//;\n1;2;3``` -> 구분자: ```;```


- [ ] 커스텀 구분자 적용하여 문자열 분리
  - 예: ```//;\n1;2;3``` → ```["1", "2", "3"]```

### 3. 계산 기능

- [ ] 분리된 문자열을 정수로 변환
- [ ] 변환된 정수들의 합 계산
- [ ] 계산 결과 반환

### 4. 출력 기능
- [ ] 계산 결과 출력 기능
  - 예: ```결과 : {숫자}``` 형식으로 출력 

### 5. 예외 처리
- [ ] 음수 입력 시 ```IllegalArgumentException``` 발생
- [ ] 숫자가 아닌 값 입력 시 ```IllegalArgumentException``` 발생
- [ ] 잘못된 구분자 형식 시 ```IllegalArgumentException``` 발생
